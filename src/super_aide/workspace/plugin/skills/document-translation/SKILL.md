# 翻译文档

原则：

- 用专门做这件事的现成工具，不要自己从零搭一套。先试译一两页，确认能出译文、排版没乱、大概要多久，再翻全文。
- 翻译服务会拿到全文。网上公开的资料（公开发表的论文、公开的手册）可以用免费服务；私人或内部的文件（合同、内部资料、个人记录……），或者看不出是不是公开的，只交给用户自己配置的服务或本机的模型，都没有就先问用户。

## 1. 弄清要什么

- 原文件在哪：浏览器里打开的本地 PDF，网址就是文件路径；在线的先下载到本地。
- 要一份译好的文件（没说就给译文版和对照版），还是只想看懂内容。只想看懂的，直接翻译或总结要点，不用装工具。

## 2. PDF（论文、手册、说明书）：PDFMathTranslate

开源的 PDF 翻译工具，保留排版、公式和图表，一次生成两份：`<原名>-mono.pdf`（只有译文）和 `<原名>-dual.pdf`（原文和译文对照）。

先看本机装没装：

```powershell
Get-Command pdf2zh_next, pdf2zh -ErrorAction SilentlyContinue
```

没装就用 uv 装进独立的环境，不碰用户自己的 Python（它要 Python 3.10～3.12，uv 会自己准备 3.12）：

```powershell
winget install --id=astral-sh.uv -e    # 本机还没有 uv 时
uv tool install --python 3.12 pdf2zh-next
```

刚装好的命令当前终端可能还找不到（PATH 要新开终端才更新），就用完整路径：pdf2zh_next 在 `%USERPROFILE%\.local\bin`，winget 装的 uv 在 `%LOCALAPPDATA%\Microsoft\WinGet\Links`。装包、第一次运行（要下载排版模型和字体）很慢或超时，多半是网络问题，见 network-proxy 技能。

选翻译服务，它决定全文发到哪里：

- `--siliconflowfree`：免费、不用 key，偶尔漏译。全文会先发到 pdf2zh 维护者的中转服务器，再转给硅基流动，所以只用在公开的资料上。
- 用户自己的大模型 key（DeepSeek、OpenAI 兼容的服务等）：译得更好，内容只到用户选的那一家；本机的模型（比如 Ollama）不出这台电脑。私人或内部的文件用这两种。
- 都没有、文件又不是公开的：先不翻。汇报第一行写「没完成：」，说明用免费服务的话全文会发到哪里，请用户选：照样用它、给一个自己的 key，或者只翻几页、由你直接翻。
- 所有服务和参数在 `pdf2zh_next -h` 的末尾，以本机装的版本为准。Bing、Google 已经不再维护。

先试译两页（下面是公开资料的例子，别的文件换成选好的服务）：

```powershell
pdf2zh_next "<原文件>.pdf" --lang-in en --lang-out zh-CN --pages 1-2 --output "<输出目录>" --siliconflowfree
```

- 打开试译的结果看一眼：是中文、排版没乱，就去掉 `--pages` 翻全文，几十页一般要几分钟。
- 输出放在原文件旁边或用户指定的地方，不要覆盖原文件。

## 3. 不要走的弯路

- 下载论文的 LaTeX 源码自己翻译、再编译：要装中文字体和一堆宏包（MiKTeX 会边编译边下载，一次就要好几分钟），模板一改常常编不过，几十页逐段翻译也很慢。只有用户明确要 LaTeX 源码，或者上面的工具效果确实不行时才考虑。
- 自己抽出文字逐页翻译、再用代码重新排版：公式、表格、图片会丢或者乱掉。
- 试译失败、装不上：不要换一条更重的路一直装下去。停下来，在汇报里说清楚卡在哪、用户可以怎么做（开代理、给一个大模型 key……）。

## 4. Word、PPT

- 几页以内：自己翻译（内容只到用户配置的服务），用 python-docx、python-pptx 逐段替换文字，保留原来的格式（见 office-automation 技能），另存为新文件。
- 篇幅长：Microsoft 365 版 Word 的"审阅 → 翻译 → 翻译文档"会生成一份译好的新文档（要联网，内容会发给微软的翻译服务）；只要能看的译文，也可以先转成 PDF，再按第 2 步翻译（翻译服务照第 2 步选）。

## 5. 汇报

译好的文件在哪（译文版、对照版）、用的哪个翻译服务、全文发到了哪里（比如"经过 pdf2zh 维护者的服务器发给了硅基流动"）；装了新工具的，说一句怎么卸载（`uv tool uninstall pdf2zh-next`）。

问答模式：不装工具、不生成文件。短的内容直接翻译；整篇文档给出上面的做法，提一句按 Tab 可以让我直接来做。
