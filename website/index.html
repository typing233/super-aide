Sees what you see看得见你的屏幕

Stop describing your screen.不用再给 AI 描述屏幕。

The moment you ask, Super Aide reads the exact text of every open window — even the parts scrolled out of view — together with a screenshot and any area you select.

提问的那一刻，它把每个窗口的文字逐字读下来——连滚动出去的部分也在——再加上截图和你框选的区域。

  • Exact text, not guesses from a picture逐字的文字，不靠看图猜
  • Apps you never want it to see — password managers by default — are blacked out不想让它看的应用（默认是密码管理器）截图里涂黑、不读文字

AltQ Ask问答

One question. It connects the dots.一句话，它把前后都串起来。

Press Alt+Q and ask in one sentence. The answer pulls together what's in every window — the error in your terminal, the deadline in a chat, the step in your notes — and leads with the conclusion. Ask mode is read-only: it never changes your PC.

按 Alt+Q，说一句话。回答会把各个窗口里的东西串起来——终端里的报错、聊天里的截止时间、笔记里的步骤——结论先说。问答模式只读，不会动你的电脑。

AltW Act操作

Or let it do the work.或者，让它直接动手。

Press Alt+W and say what you want done. It works across the command line, files, desktop apps and web pages, shows each step as it goes, then tells you what changed and how to undo it. Press Esc to stop it at any time — and keep using your PC while it works.

按 Alt+W，说要做什么。命令行、文件、桌面软件、网页都能操作，每一步都看得到，做完告诉你改了什么、怎么撤销。随时按 Esc 停下；它干活的时候，你照常用电脑。

Step by step手把手

Rather do it yourself? It points the way.想自己来？它给你指路。

Ask how to do something and it circles exactly where to click, numbered in order, right on your screen.

问它怎么做，它在屏幕上把要点的地方按顺序圈出来、标上编号。

And it keeps getting better.而且，它会越用越好。

For you — and for everyone.对你如此，对所有人也是。

Routing that learns会学习的路由

Picks the best — then learns to spend less.先挑最好的，再学着省钱。

For every request it picks Claude Code or Codex (or DeepSeek Harness), the model, and how hard to think. Every result teaches it: your 👍 and 👎, follow-ups, failures. While you're idle, it quietly answers some questions again with a cheaper setup and lets a strong model judge both. It switches only when it's 90% sure success won't drop — and if a round fails, the next one gets a stronger setup.

每次自动挑 Claude Code 还是 Codex（也可以用 DeepSeek Harness）、用哪个模型、想多深。每一次结果都在教它：你的 👍 👎、追问、失败。你空下来的时候，它还会用更省的配置把一些问题在后台再答一遍，由强模型来评。要有 90% 把握成功率不降才会换；某一轮没办成，下一轮自动换更强的配置。

Experience经验

Never the same mistake twice.同一个坑，不踩第二次。

When a task takes a wrong turn, it writes down what actually worked. Similar lessons merge into one and lessons that keep failing are dropped, so it never turns into a pile of notes. A lesson comes back only when the situation matches — by the error, the keywords or the meaning — at most two at a time. Say “hi”, and nothing is recalled.

走了弯路的任务，它会总结出真正管用的做法。相似的经验合并成一条，总是不管用的会被淘汰，不会越堆越多。只有情况对得上时才想起来（看报错、关键词，也看意思），一次最多两条；说一句“你好”，一条也不带。

Self-improvement自我改进

It improves itself — shaped by you.它会改进自己，由你来塑造。

A failed task, an Esc with a reason, a 👎, or a suggestion in your own words is enough. Claude Code (Opus 5.5 · max) finds the cause, changes Super Aide's own code, runs every test and gets an independent review. Nothing changes until you click Apply, and you can undo it any time. Your copy adapts to how you work — the age of personal apps.

任务没办成、按 Esc 说明原因、点 👎，或者写一句建议就够了。Claude Code（Opus 5.5 · 最高思考强度）会找原因、改超级助手自己的代码、跑全部测试，再另开会话复核。你点“生效”才换上，随时可以撤销。你用的这一份，会按你的习惯改变——应用个性化的时代来了。

Community社区共建

One fix reaches everyone.一人修好，人人受益。

If you opt in, improvements that run well for a day are submitted to the main version under your GitHub account — code only, privacy-checked, nothing from your screen. The maintainer reviews and merges them, and the next update brings them to everyone. It's already happening: 0.3.0 ships an improvement Super Aide made to itself from one user's suggestion. The more people use it, the better it gets.

愿意的话，稳定运行一天的改进会以你的 GitHub 账号提交到主版本——只有代码，提交前做隐私检查，不带你屏幕上的任何内容。维护者审核合并后，下次更新就到了每个人手里。这已经在发生：0.3.0 里就有超级助手按一位用户的建议改进自己的代码。用的人越多，它越好用。

Questions常见问题

Is it free?要钱吗？

Super Aide itself is free and open source (MIT). It uses your own Claude Code or Codex access — a subscription or an API key — which that provider bills as usual.

超级助手本身免费开源（MIT）。它用的是你自己的 Claude Code 或 Codex（订阅或 API 密钥），费用照常由对应的服务商收取。

What do I need?需要什么？

64-bit Windows 10 (1809 or later) or Windows 11, and access to Claude Code or Codex. DeepSeek Harness works as an alternative.

64 位 Windows 10（1809 以上）或 Windows 11，再加上 Claude Code 或 Codex 的使用权限；也可以用 DeepSeek Harness 替代。

Where does my screen content go?我的屏幕内容会发到哪？

Only to the model service you configured. Super Aide's own data — settings, history and what it has learned — stays in ~/.super_aide on your PC.

只发给你配置的模型服务。超级助手自己的数据——设置、记录、学到的经验——都在你电脑的 ~/.super_aide 里。

How careful is Act mode?操作模式会不会乱来？

Act mode has full access so it can actually finish the job. It reports what it changed and how to undo it, and Esc stops it immediately. When you only want to look, use Ask mode — it's read-only.

操作模式完全放行，这样才能真把事做完；做完会告诉你改了什么、怎么撤销，按 Esc 立刻停下。只想看看的时候用问答模式，它是只读的。

What does community co-building share?社区共建会分享什么？

Nothing unless you turn it on and sign in with GitHub. Then improvements that have run well for a day are submitted as pull requests under your account — code changes only, never screen content or logs. Anything that looks like personal information isn't submitted automatically, and the maintainer reviews every change before it's merged.

你不打开、不用 GitHub 登录，就什么都不分享。打开后，稳定运行一天的改进会以你的账号提交 PR——只有代码改动，从不带屏幕内容和日志；疑似含个人信息的不会自动提交；每个改动都由维护者审过才合并。

How do updates work?怎么更新？

Settings → General → Version checks for new versions. Click Update and the installer does the rest; your settings and history are kept.

设置 → 通用 → 版本 会检查新版本。点“更新”，安装器装好新版本后自动打开，设置和记录都保留。

How do I uninstall it?怎么卸载？

Windows Settings → Apps → Super Aide → Uninstall. You can choose to delete your data as well.

在 Windows 的“设置 → 应用”里找到超级助手，点卸载；可以选同时删除你的数据。
